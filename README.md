# cricket-win-predictor-and-score-predictor
Cricket Prediction Suite: Two fun Python tools!  ML-based Win Predictor (IPL &amp; T20I) using team, venue &amp; toss (Logistic Regression + smart aliases). Live Score Predictor (IPL/T20/ODI) – input overs/runs/wickets, get final score range. Lightweight, offline, beginner-friendly. Pure cricket joy! 🏏
